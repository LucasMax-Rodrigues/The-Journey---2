## 📌 Sobre o Projeto

**The Journey - 2** é a continuação do meu percurso educacional documentado no repositório anterior. Este repositório concentra-se em **desenvolvimento web prático**, com exercícios e projetos que demonstram evolução nas seguintes áreas:

- **HTML5 Semântico** e estruturação de páginas
- **CSS3 Avançado** para estilização responsiva
- **JavaScript Puro** para interatividade dinâmica
- **Autenticação e Formulários**
- **Manipulação do DOM**

Cada atividade representa um passo importante na minha jornada como desenvolvedor.

---

## 🎯 Estrutura do Projeto

### Atividades Realizadas

#### 📂 **Programa WEB - Atividade 1**
**Exploração de Elementos HTML**
- Introdução a formulários HTML5
- Diversos tipos de input (text, email, tel, date, color, file, etc)
- Listas e elementos semânticos
- Integração de imagens externas
- **Tecnologias:** HTML5

#### 📂 **Programa WEB - Atividade 2**
**Autenticação e Design**
- Desenvolvimento de página de login
- Estilização com CSS (box-shadow, gradientes, hover effects)
- Navegação entre páginas (login → cadastro → dashboard)
- Formulários com validação básica
- **Tecnologias:** HTML5, CSS3

#### 📂 **Programa WEB - Atividade 3**
**Aprofundamento em CSS**
- Layouts avançados com Flexbox
- Responsividade para mobile e desktop
- Animações CSS
- Estilização de elementos interativos
- **Tecnologias:** HTML5, CSS3

#### 📂 **Programa WEB - Atividade 4**
**JavaScript e Manipulação do DOM**
- Renderização dinâmica de dados
- Manipulação de tabelas com JavaScript
- Consumo de dados (simulado ou via API)
- Operações CRUD básicas
- **Tecnologias:** HTML5, CSS3, JavaScript
